# cbpi4-UITheme

Плагин CraftBeerPi4: цвета и шрифты интерфейса настраиваются прямо в Settings (вкладка "UI Theme"), без установки каких-либо патчей.

- 11 полей цветов в формате #RRGGBB (UI_THEME_PRIMARY_COLOR, UI_THEME_SECONDARY_COLOR и т.д.);
- 3 выпадающих списка шрифтов (UI_FONT_MAIN, UI_FONT_PLOT, UI_FONT_CARDS);
- значение "Original" оставляет оригинальный цвет или шрифт.

## Как это работает

Плагин при каждой загрузке страницы отдаёт браузеру главный файл интерфейса с подставленными цветами и шрифтами. Файлы на диске не меняются, поэтому удаление плагина (`pip uninstall cbpi4-UITheme`) сразу возвращает оригинальный вид. После изменения настройки достаточно обновить страницу (F5), перезапуск CBPi4 не нужен. Если после обновления интерфейса какая-то замена не подходит, она пропускается, остальное работает, предупреждение пишется в лог.

Остальные изменения интерфейса (размеры окон и уведомлений, кнопки +/-) остаются в [cbpi4-ui-patch](https://github.com/zzorrro/cbpi4-ui-patch).


## Свои значения по умолчанию и новые шрифты

Правьте словари COLORS и FONT_OPTIONS в начале `cbpi4_UITheme/__init__.py`, инструкция в комментариях. Сохранённые на сервере значения при обновлении не затираются. Неверный цвет заменяется значением по умолчанию при перезапуске, а на странице игнорируется.

## Установка одной командой

    curl -fsSL https://raw.githubusercontent.com/zzorrro/cbpi4-UITheme/main/install.sh | sudo bash

Скрипт сам находит Python, в котором стоит CraftBeerPi4 (в том числе виртуальное окружение), ставит плагин и перезапускает службу craftbeerpi. Если не нашёл: `sudo CBPI_PYTHON=/путь/к/python bash install.sh`. Удаление: `sudo bash install.sh remove`.
